## Dropped, with the reason
| Stitch element | Why |
|---|---|
| Archivo Narrow | 90 KB width axis on the field; one family only (memlog, app.css) |
| Material 3 colour front matter (`#755b00` …) | Generated by Stitch, not the brand tokens |
| Material Symbols | The repo uses Lucide; an icon font is a new dependency |
| Radius 8/16 and the drawn 2–8px | Memlog 6/12 |
| "Zéro ligne" separation by shadow, coloured edges on KPI cards | Surfaces decision: border + faint shadow, edges only where there is a status |
| Converti in gold (A9, A10), white on gold (A9) | Gold rules; Converti is success |
| Monospace (A4–A6, A11) | Banned in Prompt 0 |
| Status colour cues on outcome icons (F3) | Invariant 3: the phone never previews status |
| Spec text on screen, F8 as a spec sheet | Not UI |
| SIRET/BCE, geocoding, NAF, "Qualification terrain", import history, RGPD panel, merge tolerance card, agent preview, route optimisation, printing, telemetry, voice notes, prices | Invented, with nothing behind them in the back end |
| Offline tile cache ("54 Mo téléchargés") | OSM tile policy; memlog assumes no tiles offline |
| Duplicate pending card with "Envoyer" (F1) | Sync strip decision |
| The chart's own 7J/30J/90J switch (A1) | Duplicates the header period selector `[ASSUMPTION]` |
| "Taux de signature terrain" (A1) | Duplicates Taux de conversion |
| Raised gold "Ajouter" tab | `[ASSUMPTION]` it would read as the main action on every screen |
| F1 tablet and desktop drawn in the admin shell | The field tablet uses the band tabs; the admin round view is its own surface |
