/login visual refresh

Idea: give /login a modern look, with behaviour, fields and elements unchanged.
Outcome: hardened. After 15 mockups, option 3o was locked.

The locked design

Locked decisions

  • Plain off-white page — no band, no ruled background
  • Navy mark + “Captain Prospectus” (22px/700) centred above the card, phone and desktop
  • Card: max 24rem, soft shadow, 4px gold top edge
  • “Connexion” (text-title, 20px/600, still the h1) and the lede centred in the card; the form is unchanged
  • Smooth type steps: brand 22/700 → Connexion 20/600 → labels 16/500
  • Gold edge is the single written exception to “gold has two jobs” in design.md › Colour

Weak points that survived

  • 22px brand size has no token: add text-brand to @theme
  • Sally still prefers a navy edge; the gold one is now a documented exception that has to stay the only one
