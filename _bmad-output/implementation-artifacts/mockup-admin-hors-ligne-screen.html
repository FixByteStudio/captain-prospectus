Behaviour

  • Réessayer calls the shell's existing recheckIdentity (one /api/me, shared in-flight guard). While it runs the button is disabled with a spinner and reads « Vérification… ».
  • Answer is live admin → the admin chunk loads in place, same URL (the AdminFrameFallback band, then the dashboard).
  • Still unreachable → back to idle « Réessayer ». No toast, no extra line: the screen already says what to do.
  • 401 → /login, as today.
  • The network coming back re-checks on its own (today's online effect), so Réessayer is never the only way out.
  • No « Retour à la tournée » link: ADR-0037 removes the admin field side (story 4 removes the rest).
  • Admin already on a dashboard when the network drops (live identity) keeps today's offline Alert banner — not this screen.
