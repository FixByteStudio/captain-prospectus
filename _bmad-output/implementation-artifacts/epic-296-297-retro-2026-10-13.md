### Diff-scope review (code lenses)

**F5: migration 0015 copies `sessions` into a NOT NULL `id` with no guard** (#297 adversarial and edge-case lenses; #297 verification-gap lens).
- What happened: `drizzle/0015_old_mantis.sql:12` is an `INSERT … SELECT` from `sessions`. Any row with a null `id` would abort the migration.
- Why it is low risk here: 0012 backfilled every row, every insert since #307 writes an id, and the deploy at `908566d` applied it (Deploy `success`, 2026-10-13T15:21). The data stage is disposable.
- What is missing: no test applies a migration over rows that already exist. The deferred-work entry from `spec-gh-307` still says so, with no `closed_by`. `migration-guard` did not run on #478 (PR body: "`migration-guard` and the other review subagents were not run in this change").
- **Accept the instance.** Lesson: a migration that rebuilds a table runs `migration-guard` (action 6).
