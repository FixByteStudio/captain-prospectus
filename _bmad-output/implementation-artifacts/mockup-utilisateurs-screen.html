What changes

  • Title, sidebar item and breadcrumb read « Utilisateurs »; the URL stays /admin/users.
  • Lede becomes « Qui peut se connecter, et sur quels appareils. » — the role is no longer something you set here.
  • Two sections in this order: Administrateurs, then Agents. Each heading carries its active count in muted tabular figures, then its own Surface with the same columns minus Rôle.
  • Rows, expansion, device lines and the row menu are unchanged (no role item since #593).
  • With no active agent, the Agents section shows one muted line: « Aucun agent actif. Ajoutez-en un avec « Ajouter un utilisateur ». » The Administrateurs section is never empty (the reader is one).
  • Désactivés stays one collapsible list under both sections, and keeps its Rôle column, since it mixes both roles.

Ajouter un utilisateur

  • « Rôle » moves first and gets a description: the role is set once, here.
  • Options read « Agent » (default) and « Administrateur ».
