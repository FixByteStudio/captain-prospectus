Utilisateurs — #594, story 2.6 (R8, ADR-0037)

The Agents screen becomes Utilisateurs at /admin/users (nav label too). One header and one « Ajouter un utilisateur » button, then two sections, Agents first, then Administrateurs, each a heading with its count over its own Surface. The Rôle column goes: the section says it. Each section keeps its own « Désactivés (n) » toggle under it, so a deactivated row never needs a role either. Rows, badges, device lines and the row menu are unchanged from today.

What changes

  • Title and nav: « Agents » → « Utilisateurs ». Lede drops « avec quel rôle » since the role no longer changes: « Qui peut se connecter, et sur quels appareils. »
  • Two sections in a fixed order, Agents then Administrateurs; heading in text-heading, count in meta, tabular.
  • No Rôle column (desktop) and no « · Agent » in the meta line (phone).
  • « Désactivés (n) » sits under the section it belongs to; absent when that section has none.
  • An empty Agents section shows one muted line in its Surface: « Aucun agent. Ajoutez-en un pour lancer les tournées. » Administrateurs is never empty (you are in it).

Unchanged

  • Row expand → device lines, Révoquer, « Cet appareil ».
  • Row menu: Générer un code · Nouvelle phrase de passe (own row) · Désactiver (last admin disabled + reason).
  • Loading skeleton, load failure, deactivate dialog, code and passphrase dialogs.
